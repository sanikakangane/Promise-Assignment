# Promise-Assignment

A simple JavaScript project that uses Promises to simulate a recruitment process with three stages:

* Coding Assessment
* Technical Interview
* Final Selection Review

## Files

* `question1.js` – Coding Assessment
* `question2.js` – Technical Interview
* `question3.js` – Final Selection Review

## Concepts Used

* Promises
* `setTimeout()`
* `.then()`
* `.catch()`
* `resolve()` and `reject()`
* Average calculation

## How to Run

```bash
node question1.js
node question2.js
node question3.js
```

## Expected Output

### Question 1

```text
Coding Assessment Cleared
Average Score: 75
```

### Question 2

```text
Technical Interview Cleared
Average Score: 77.5
```

### Question 3

```text
Final Selection Cleared
Final Average: 76.25
```

If the candidate does not meet the cutoff, the corresponding failure message will be displayed.
